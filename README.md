## Project Overview

The Intelligent Campus Resources Optimization System is designed to manage
the allocation of shared campus resources such as classrooms, laboratories,
projectors and sports facilities.

The system aims to handle resource availability, overlapping requests and
priority-based allocation efficiently.

## DSA Concepts

The project explores the application of:

- Binary Trees
- AVL Trees
- Min Heap
- Priority Queue
- Tree Traversal
- Graphs
- Adjacency List / Adjacency Matrix
